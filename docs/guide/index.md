# Cursuri

Cursuri complete pentru elevii care vor să învețe programare de la zero. Fiecare curs e structurat săptămânal, cu exerciții și mini-proiecte la final de lecție.

---

## Cursurile disponibile

### Dezvoltare Web

Învață să construiești site-uri complete — HTML pentru structură, CSS pentru design și JavaScript pentru interactivitate. La final vei avea un portofoliu online, un quiz interactiv și o aplicație meteo conectată la un API real.

- **Lecții:** 22 (plus pagină introducere)
- **Durată:** ~1 an școlar (septembrie – iunie), 90 min/săptămână
- **Nivel:** începător
- **Tehnologii:** HTML5, CSS3, JavaScript ES6+
- **Proiecte finale:** Portofoliu personal, Quiz cultural, Aplicație meteo

[**Începe cursul Web →**](web/index.md)

---

### Programare Python

De la `print("Salut")` până la jocuri text și grafice cu `turtle`. Înveți variabile, condiții, bucle, funcții, fișiere și structurile de date esențiale.

- **Lecții:** 12 (plus pagină introducere)
- **Durată:** ~un semestru, 1–2 ore/lecție
- **Nivel:** începător
- **Tehnologii:** Python 3, Thonny IDE
- **Proiecte finale:** Joc de aventură text, desen cu Turtle

[**Începe cursul Python →**](python/index.md)

## Cum alegi între ele?

| Dacă vrei să... | Alege |
|----------------|-------|
| Construiești site-uri web | **Web** |
| Înveți bazele logicii algoritmice | **Python** |
| Lucrezi cu date și automatizări | **Python** |
| Faci interfețe vizuale imediat | **Web** |
| Te pregătești pentru proiecte cu microcontrollere | **Python** (sintaxa se transferă la MicroPython pe ESP32) |

!!! tip "Poți învăța și ambele"
    Web și Python nu se exclud — mulți programatori profesioniști folosesc ambele. Începe cu cel care te motivează mai mult, apoi adaugă-l pe al doilea.

## De ce aceste cursuri?

- **Gratuite și open-source** — toate lecțiile sunt aici, fără înregistrare
- **În limba română** — explicații clare, fără jargon netradus
- **Cu exemple concrete** — nume și contexte familiare (Cluj, Chișinău, București)
- **Cu feedback imediat** — fiecare lecție are exerciții și soluții
- **Cu mini-proiecte** — construiești ceva concret la final de fiecare lecție

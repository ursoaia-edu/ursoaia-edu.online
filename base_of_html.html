Curs Web — Bazele HTML

Tutoriale video în limba română despre HTML, CSS și JavaScript — fundamentele dezvoltării web moderne. Ideale pentru absolut începători.

Ce vei învăța:

  • Media queries (responsive)
  • JavaScript de bază
